# 页面结构与线框

版本 0.2。ID 与 [需求说明](需求说明.md) 一致，共 18 个计划页面。线框只表达结构，**所有可见面均采用 DESIGN 的蓝青柔光、圆角玻璃和双主题**；不能依据 ASCII 方框生成低圆角仪器面板。样例数字与文案必须标注为设计示例。

## 1. 外壳：全部登录后页面

```text
柔光背景：浅蓝 → 浅青 → 极淡粉；深色使用对应三色
┌ 232px 圆角玻璃侧栏 ┐   面包屑                         主题  账号
│ 品牌标记 春雨孕算   │   页面标题                       [主操作]
│ 管理工作台          │   说明 / 持续状态提示
│ 工作台              │
│ 内容中心            │   ┌ 24px 圆角 strong 玻璃工作面 ─────────┐
│ 审核发布（按阶段）  │   │ 筛选/正文/列表/操作，以页面模板决定   │
│ 系统管理            │   └───────────────────────────────────┘
└───────────────────┘
```

232px 是导航本体宽度，侧栏外留 16px。64px 顶栏与页面内容对齐，背景不加第二张大渐变卡。能力与权限决定入口，阶段 A 不展开未具备的队列导航。

## 2. W01 登录

横向居中的品牌说明 + 420px 登录卡。左侧是现有品牌图标、产品名、“内容维护、审核与发布”，以及三条真实能力说明；右侧 strong 玻璃表单卡：用户名、密码/显示、错误区、登录按钮。无公开运营数、无心电图、无孕周轴、无社交登录假入口。

窄屏隐藏非必要说明，保留品牌和全宽表单。密码输入不回填演示凭据。交付默认、错误、限流、登录中、会话过期提示以及双主题。

## 3. W02 工作台

阶段 A：顶部标题与当前角色说明；一张蓝青品牌卡承载“内容维护工作台”及本角色主要入口，卡片内文字与按钮满足对比；下方是授权任务入口和已实现/未实现能力清单。没有数据接口就不出现空 KPI 墙。

阶段 B 真实统计接通后的结构：

```text
工作台                           时间范围  数据更新时间  刷新
┌ 蓝青重点卡：主要任务与入口 ┐ ┌ 玻璃指标：待审核/待发布 ┐
└──────────────────────────┘ └─────────────────────────┘
┌ strong 工作面：用户新增趋势 2/3宽 ┐ ┌ 我的待办 1/3宽 ──┐
│ 有真实曲线 + 数据表入口            │ │ 标题/版本/状态/入口│
└──────────────────────────────────┘ └──────────────────┘
┌ 最近审核发布动态（权限与接口支持时）────────────────────┐
└───────────────────────────────────────────────────────┘
```

今日活跃没有埋点契约时显示未接入，不放 0、增长箭头或示意折线。全屏展示不是首期必需页面；若后续增加，只复用现有主题，不建立霓虹大屏风格。

## 4. W03 用户列表、W04 用户详情（阶段 B）

列表：标题/数据范围说明 → 服务端搜索与筛选（契约确认后）→ 匿名标识、状态、建号时间、会话摘要 → 分页。详情：面包屑 → 匿名账号标题 → 只读基础资料卡与获授权的会话摘要。

不展示孕期、超声报告、电话、医院、位置；不放“查看健康档案”空按钮。缺 API 显示能力状态，不显示仿真用户列表。

## 5. W05 知识列表

```text
知识内容                                  [新建知识]
维护同一版本的专业表达、白话表达与来源
┌ strong 玻璃表格面 ───────────────────────────────────┐
│ 筛选条：阶段 B 才提供全库搜索/分类/状态                │
│ 标题/slug     分类    最新版本/状态   当前版本标识  操作 │
│ 胎儿生长测量  生长    v4 待审核       非当前发布   查看 │
│ 羊水指数      羊水    v2 已发布       当前发布     查看 │
│ [上一批]                          每批20   [下一批]   │
└─────────────────────────────────────────────────────┘
```

默认摘要没有作者和更新时间，不能在阶段 A 假装这些是列表已返回字段。当前最新版本不是当前发布时，只显示“非当前发布”，具体在详情/版本历史查询，不猜测发布版本号。首列文本详情链接与行操作分开；本人 draft 才能进入可编辑状态。

## 6. W06 新建、W07 编辑版本

宽屏采用 1200px 阅读/编辑宽度：

```text
知识内容 / 新建或编辑               草稿状态 / 最近保存结果
┌ strong 玻璃基本信息 ─────────────────────────────────┐
│ 标题                                                  │
│ slug（仅新建）                     分类                │
└──────────────────────────────────────────────────────┘
┌ 专业表达 strong 面 ─────────┐ ┌ 白话表达 strong 面 ────┐
│ 纯文本输入，保留可读行高      │ │ 同一版本，始终保留数据  │
│ 字数/上限 + 错误区           │ │ 字数/上限 + 错误区     │
└────────────────────────────┘ └───────────────────────┘
引用来源：多条纯文本引用 + 添加/移除 + 校验说明
编写依据：多行输入，始终必填
底部 strong 操作条：[取消] [创建草稿 或 保存草稿] [保存并提交审核*]
```

*“保存并提交审核”仅已创建草稿显示；先保存成功再确认送审。单个表单不再额外嵌一层重阴影大卡。未保存、保存中、保存失败、已保存、409 冲突都保持两份正文。窄屏双表达改纵排并保留小节锚点。

## 7. W08 版本详情与历史

标题、分类、版本号、状态、当前发布标识 → 专业/白话只读双栏 → 引用与依据 → 版本信息与历史页签。顶部按权限和实际状态提供“编辑草稿”“新建修订”“审核”“发布”“下架”。不能一次摆满所有可执行状态按钮。

历史页签使用版本摘要和游标；选中历史版本后显示该版本完整正文。旧版若曾 published 但不是当前指针，用“曾发布 · 非当前”解释，不误标“App 当前版本”。

## 8. W09 审核队列（阶段 B）、W10 审核详情

W09：标题 → submitted 服务端筛选 → 左侧任务列表、右侧所选摘要与开始审核。摘要真实字段不足时不推断“待我审核”。窄屏转普通列表进详情，不挤压主从栏。

W10：面包屑、版本与作者标识 → 专业/白话只读双栏 → 来源、依据与历史 → 审核意见 → [驳回] [批准]。现有详情没有提交时间，阶段 A 不伪造该字段；作者显示名也需真实人员映射才展示。作者本人访问时显示不可自审说明；阶段 A 从 W08 进入并返回 W08。批准/驳回确认都指明版本，失败保留意见。

## 9. W11 发布中心（阶段 B）

待发布/当前发布视图 → 真实服务端列表 → 版本详情入口及发布/下架动作。不能从当前知识页过滤 approved 后命名“全部待发布”。阶段 A 发布/下架在 W08 执行，不强行跳转空列表。

发布确认：条目名、版本号、“此操作更新管理库；App 分发尚未接通”、取消/发布。下架确认：当前版本、管理库指针变化、保留历史、App 缓存撤回边界。

## 10. W12 管理员列表、W13 新建、W14 编辑

列表：用户名、显示名、状态、角色、操作；按实际摘要字段绘制，A 用游标，B 再加远程筛选。

新建：用户名/显示名/初始密码/预置角色；显示密码可键盘切换。编辑：显示名/状态/角色，单独的重置密码区域，不把停用与普通保存按钮并列为相同强调级。角色或状态变化说明撤销目标会话，处理最后一名安全管理员保护。

直接打开编辑链接但无法取到最新账号摘要时显示重新加载/返回列表，不展示可提交的旧 revision 表单。

## 11. W15 角色权限

只读矩阵：角色、角色说明、服务端返回的权限码与中文任务说明。没有“新增角色”“编辑权限”“全选权限”按钮。矩阵只读也需要横滚和行列关联可访问性。

## 12. W16 操作审计

只读游标列表：发生时间、操作人、资源、动作、结果、requestId；真实接口缺少的附加字段不补造。requestId 截断 + 可聚焦全文/复制；复制只提示“已复制”。阶段 B 筛选设计单独标注。

不提供删除/编辑，不把审计结果当服务器健康。详情说明中不出现密码、token 或正文全文。

## 13. W17 系统能力

分组展示 auth、operators、roles、audit、knowledgeWorkflow 等已实现能力，以及 miniappContentDelivery、modelRelease 等未实现能力。明确说明：能力清单不等于当前运行健康。

数据库/Redis 延迟、在线状态、最后同步时间目前无对应探测接口，不画成绿色正常监控卡。

## 14. W18 本人改密

最大 560px strong 表单：旧密码、新密码、前端确认新密码（不发给 API）、策略说明、表单错误、取消/修改密码。成功进入登录，清除秘密与当前会话。不在此编辑 App 用户隐私设置。

## 15. 必备状态与双主题

每种列表模板：初次加载、已有内容刷新、空数据、无结果（B）、接口失败、离线旧数据、权限不足、未接入。每种表单/详情：未保存、busy、字段错误、会话失效、409、成功；选择器展开、日期范围、危险确认、导航抽屉也必须出稿。

状态页沿用同一外壳与玻璃工作面，不能突然变成纯白组件库默认页或深色报错终端。验收矩阵以 [运行与验收](运行与验收.md) 为准。
