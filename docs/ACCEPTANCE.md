## 2. 设计验收

| 维度      | 通过条件                                                         |
| --------- | ---------------------------------------------------------------- |
| App一致性 | 并排对比品牌蓝青、柔光三色、24/16/12圆角、玻璃工作面、字体与图标 |
| 桌面适配  | 表格、筛选、双栏审核与侧栏源于共享设计，未复制手机壳             |
| 双主题    | 默认/展开/错误/禁用/忙碌/确认/图表和滚动条同源；不只替换底色     |
| 阅读      | strong面承载长文表格，实际合成背景测对比，不假定渐变白字天然合格 |
| 计数      | W01-W18有覆盖表；画板/状态/路由分别计数                          |
| 数据诚实  | 演示数据有标识；未接入、暂无数据、失败分开；无虚构运营趋势       |
| 流程      | 创建、编辑、送审、非作者审核、发布、下架和返回来源各有连接       |
| 能力边界  | 搜索/队列/统计的B阶段依赖明确，能力不冒充健康监测                |

首批四页通过后展开其他页；每次共享令牌变更重新对照 App，不以“更像标准后台”为由替换品牌。

## 3. 工程验收目标（覆盖以实现记录为准）

| 主题      | 必测结果                                                              |
| --------- | --------------------------------------------------------------------- |
| 身份/权限 | 各预置角色、组合角色、401/403、作者自审拒绝、直接路由访问             |
| 游标      | 下一批/上一批、末批、每批数量变化、返回恢复、刷新缺前驱栈             |
| 内容      | 双表达与依据校验、引用送审门禁、纯文本转义、草稿编辑权限              |
| 发布      | 非approved拒绝；管理库范围提示；旧版非当前；下架保留历史              |
| 幂等      | 同动作超时重试同key/UUID；载荷变化新key；重复点击不重复审计           |
| 并发      | 条目/版本/账号revision正确；409保留输入；428不盲重试                  |
| 管理员    | 角色/停用撤销会话；最后安全管理员保护；直接编辑缺摘要恢复             |
| 搜索增强  | 仅在服务端契约具备后测试；IME、防抖、清除、旧响应取消                 |
| 会话/离线 | 无离线写队列；过期重登后重验权限与版本；不持久化秘密或正文            |
| 可访问    | 键盘/焦点、label、错误关联、Dialog trap/Escape/回焦、通知live region  |
| 视觉      | 两主题、模糊降级、长标题/空列表/长文、减少动态、对比度                |
| 视口      | 1280×720、1440×900、1920×1080；1024/1279断点；390px关键可达；200%缩放 |

Chrome/Edge 的支持版本在真正发布时确认，不在静态文档中承诺未测试环境。每个结论附浏览器、接口环境、截图/用例路径与日期。
