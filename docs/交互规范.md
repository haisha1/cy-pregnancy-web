# 管理端交互与行为契约

版本 0.2 · zh-CN · Asia/Shanghai · 公历。读者为编辑、审核、发布及安全管理员。视觉统一由 [视觉设计规范](视觉设计规范.md) 负责；领域状态与接口以 [接口契约](接口契约.md) 为准。

## 1. Canonical UI Map

以下为实际运行时所有者，组件位于src/components、共享行为位于src/composables；同名Figma组件已建立。所有页面使用共享组件，不能自己再写第二套确认框、分页或反馈逻辑。

| Capability      | Canonical owner               | Source of truth | Allowed variants           | Verification         |
| --------------- | ----------------------------- | --------------- | -------------------------- | -------------------- |
| Table Selection | 首期不提供批量选择            | REQUIREMENTS    | none                       | 检查无假批量框       |
| Select/Listbox  | CySelect                      | 本文 + DESIGN   | authored, single/multiple  | 展开态/键盘/主题     |
| Date            | CyDateRange                   | 本文            | authored, date-only        | 中文日历、范围与回焦 |
| Form            | CyInput / ContentEditor + domain/content | 本文 + DTO      | create/edit/read           | 错误关联/首错焦点    |
| Scrollbar       | 全局主题样式                  | DESIGN          | document/table-viewport    | 页面与表格边界       |
| Toast           | CyDialogProvider + useUi        | 本文            | success/info/warning/error | live region/去重     |
| CRUD            | 路由、服务层、编辑守卫        | 本文 + API      | stay/detail/return         | 完整往返流程         |

## 2. 导航、列表与搜索

- 标题使用“页面名 · 春雨孕算管理端”。面包屑表达资源层级，页签表达同资源不同视图；详情返回来源列表及原条件。
- 侧栏按权限隐藏无关模块。直接访问无权限页面显示 403；不存在显示 404；能力未实现不是 403，也不是空列表。
- 已有 API 只使用 `beforeId/limit`，默认 20，可选 20/50/100。以客户端游标历史实现“上一批/下一批”，切条件重置游标栈。不显示总页数、任意跳页或虚构总条数。
- 列表已提交的筛选和游标状态进入 URL，敏感字段不进 URL；返回时恢复滚动。刷新游标栈丢失时回到可确认的起始批次，不能猜测上一游标。
- 知识/管理员/审计已支持服务端搜索与筛选，不能只过滤当前20行。参数范围见API-CONTRACT。
- 搜索 300ms 防抖，Enter 立即提交；输入法组合期间不触发，结束后提交。非空提供可键盘清除按钮，清除立即生效并回焦；取消或忽略旧响应，防止旧请求覆盖新结果。
- 表格首列有真实详情链接，操作按钮不触发行导航；语义 table，表头 scope，排序只在服务端支持时提供。截断标识有可键盘访问的全文与复制方式。

## 3. 表单与验证

标签在控件上方，必填与帮助文字明确。使用 noValidate，字段错误由应用管理，不弹浏览器原生验证气泡。提交时校验所有字段，展示错误摘要并定位首个错误；出错字段后续 blur/change 复核，未触碰字段不持续报错。

错误区预留高度，按钮 busy 时固定宽度。textarea 使用 resize:none，保留足够高度并提供自动增长或展开编辑，不允许页面因为自由拖拽失去对齐。

双表达始终同时存在，宽屏并排，窄屏纵排；预览切换只改变阅读区，不丢另一份正文。App 全局专业/白话模式不作为 Web 顶栏开关。

草稿只能由本人编辑；页面即使处于可编辑状态，提交前仍处理服务端权限或状态变化。引用条数与字段上限来自 API-CONTRACT，不单独定义第二套。

## 4. 操作结果登记

| 操作            | 提交时                      | 成功去向与反馈                                       | 失败与焦点                                     |
| --------------- | --------------------------- | ---------------------------------------------------- | ---------------------------------------------- |
| 登录            | 防重复；保留用户名          | 校验安全 returnTo 后进入目标，否则工作台             | 留页；密码不持久化；错误靠近表单               |
| 创建知识        | 固定按钮 busy               | 进入新版本详情，“草稿已创建”                         | 保留输入，首错字段或全局状态                   |
| 保存草稿        | busy，不重复提交            | 留编辑页，“草稿已保存”，更新 revision                | 保留输入，冲突不覆盖                           |
| 保存并送审      | 先保存，确认后独立送审      | 版本详情，“已提交审核”                               | 保存成功/送审失败分别显示；保持已保存 revision |
| 批准/驳回       | 确认目标版本与意见后提交    | 有来源队列则返回原队列；否则回版本详情               | 保留意见与弹窗；无队列不能跳到空壳页           |
| 发布            | 确认管理库范围，弹窗 busy   | 有队列回队列，否则版本详情；“管理库已发布”           | 弹窗内错误，允许安全重试                       |
| 下架            | 说明条目及影响，确认后 busy | 当前版本详情；“已从管理库下架”                       | 保留状态，不假定 App 缓存已撤回                |
| 创建/修改管理员 | 状态或角色变化先确认        | 回原列表，定位目标行或显示定位提示                   | 保留非秘密输入；展示最后管理员保护原因         |
| 重置密码        | 确认目标，密码默认遮蔽      | 更新成功后清空秘密；说明目标会话撤销                 | 不回显密码至通知或日志                         |
| 本人改密        | 验证旧/新密码并提交         | 清除当前登录状态，进入登录；“密码已修改，请重新登录” | 留页修正，不存密码                             |
| 取消/返回       | 脏表单先询问                | 回来源，恢复列表条件和焦点                           | 可选择继续编辑                                 |

首次新建页面默认“创建草稿”，后续才提供“保存并提交审核”，避免创建成功后 UUID/revision 尚未知就连发状态请求。服务端成功后刷新详情；幂等回执不是最新详情。

## 5. 弹层、选择器与反馈

- 统一 Dialog/AlertDialog，包含标题、说明、焦点陷阱、背景 inert、关闭策略与触发点回焦。应用内不用 window.alert/confirm/prompt。
- 下拉和日期 authored 组件负责方向键、Enter、Escape、边界碰撞、滚动上限与焦点恢复；中文日历不依赖系统英文弹层。此处的 authored 是共享可访问组件，不是每页手写弹层。
- 浮层层级从低到高：sticky 内容、popover、导航 drawer、dialog、全局通知。模态弹层出现时关闭背景非模态弹层，通知不抢焦点或遮挡确认按钮。
- 发送写请求时禁止重复提交；不要把关闭弹窗当成取消服务器动作。请求结果未知时维持可恢复的动作上下文，避免重新生成 key。
- 成功提示 4 秒，信息 6 秒；可恢复错误留在相邻区域。右上角通知单队列、去重、带 live region；关键错误不只在 toast 中出现。
- 送审使用中性确认，角色/停用/下架说明后果，危险操作按钮直接写动作名。日常可逆保存不增加无意义确认。

## 6. 异步、冲突与恢复

采用悲观更新，服务端明确成功后再改状态。只读请求可重试，写请求按 [接口契约](接口契约.md) 保留单次操作的幂等 key、创建 UUID 与载荷。修改载荷或开始新动作时换 key，原动作超时重试不得换 key。

409 先区分版本冲突、状态冲突与幂等载荷冲突。保留当前输入并提供“查看最新版本”；不自动把旧正文覆盖新版本。428 是调用方漏传前置版本，不能当普通冲突点击无限重试。

401 清除 token、重新登录并重新取权限。未提交内容只在当前内存会话暂存，不进入 localStorage/sessionStorage；刷新或关闭浏览器不承诺恢复。重登录后检查当前版本/权限，再决定恢复输入。returnTo 仅允许同源已登记路径。

离线显示真实提示和已有只读内容，写操作不进入队列；数据过期标注上次成功更新时间。503/超时不把数据设为 0，也不更新“最近成功刷新”。

脏表单的应用内导航使用共享离开确认；真正刷新/关页仅使用浏览器 beforeunload 的有限机制。确认文本不包含密码或正文全文。

## 7. 主题、响应式与可访问性

双主题同步覆盖导航、控件展开态、图表、错误、确认、禁用、滚动条，不能只换页面底色。主题变化保留输入与焦点，prefers-reduced-motion 下关闭位移动画。

宽度变化按 DESIGN 断点执行。390px 可达关键流程，200% 缩放仍能访问长表单尾部和操作；宽表格在有名称的区域横滚。默认不同时固定首列与操作列到占满窄视口，窄屏优先保留识别信息，操作列可滚动进入。

语义按钮/链接、可见 focus-visible、字段真实 label、aria-invalid/aria-describedby、图标按钮中文名称、状态 live region、对比度与颜色之外的状态表达是基线。秘密默认遮蔽且允许粘贴和密码管理器；显示切换按钮必须有动态可访问名称。

## 8. 日期、权限与敏感信息

服务时间 UTC 转为 Asia/Shanghai，显示 `YYYY-MM-DD HH:mm` 并可查完整时间；仅日期字段仍保存 YYYY-MM-DD，不先当作 UTC 时间再偏移。统计日期范围按北京时间明确起止边界。

无关模块隐藏；已知同资源因状态受限的动作禁用并说明；服务未实现不伪装为权限不足。复制 UUID/requestId 的通知只显示“已复制”，不回显值。日志/分析不含正文、密码、token 或健康输入。
