# 本轮实现与验证

日期：2026-10-19。Web从文档包落地为Vue3+TypeScript+Vite工程，两套Java服务保留现有架构，补齐管理端所需接口，不另建一套Node后端。

## 实现范围

- 18类业务页面：登录、工作台、用户列表/详情、知识列表/新建/编辑/详情、审核列表/详情、发布中心、管理员列表/新建/编辑、角色、审计、能力、改密；额外提供知识修订页及403/404公共状态。
- Cy公共组件统一输入、搜索、选择、日期、表格、分页、确认和状态；主题由App palette生成。专业/通俗内容同时编辑，引用与证据说明随版本保存。
- 管理服务增加仪表盘、用户只读聚合、远程筛选、跨条目队列、管理员详情、真实依赖探测。角色通过V2迁移补权限，写流程保留事务、幂等、乐观锁和作者不能自审。
- 用户服务提供内部匿名账号查询和注册统计，独立密钥校验，禁止通过外部Nginx代理内部路径。旧账号迁移回填随机公开UUID，新账号由Java生成UUID，不返回微信标识和凭据。
- 中文检索对ASCII用户名/slug/UUID列显式转换UTF-8比较，并转义LIKE特殊字符，避免中文条件引发字符集错误或将用户输入误作通配符。
- 401清会话并恢复同账号本标签页知识草稿；409保留输入、明确加载新版本；传输失败重试复用key；离开保护、IME搜索、移动导航、深浅主题与键盘操作已联调。

## 部署与运行

生产部署见 [Jenkins + Docker 部署步骤](部署说明.md)：Jenkins 构建 dist，Compose 发布 Nginx，宝塔代理到本机 18080。保留健康检查、日志轮转及 API 代理；服务器运行和后端联调需单独验收。

本机启动见 [项目说明](项目说明.md)，脚本不展示随机密码/密钥，前端VITE变量不得放秘密。生产构建dist目录，Nginx样例见 [配置](../deploy/baota-docker.conf.example)，需提供实际HTTPS证书、管理入口访问控制和服务配置。

两个服务通过环境变量配置相同的ADMIN_READ_KEY（至少32字符、独立随机值），管理服务另配USER_READ_URL，容器中不能沿用127.0.0.1指向另一容器。JWT_SECRET与ADMIN_JWT_SECRET仍分开。生产禁用bootstrap，使用已有安全管理员管理其他账号，不授予所有角色作默认值。

管理API保持同源；入口HTML不长期缓存，哈希资源长缓存；内部用户查询仅在受控服务网络可达，MySQL/Redis不公开。上线前使用项目既有备份、迁移、最小数据库权限、可用性监控和恢复流程。Java8/Spring Boot2.7旧基线需要后续维护升级。

## 保留边界

知识发布已由用户服务提供游客只读接口，App可浏览当前版本；公式和参考参数不会随内容更新。医学模型发布、OCR、云同步、反馈工单、用户停用/删除、MFA与回滚未接通，在能力页明确显示。没有把用户匿名查询扩展成健康档案桌面镜像。

Bearer只在内存，页面刷新需要重新登录；草稿暂存不跨刷新。列表没有总数/随机页码。详情没有submittedAt/updatedAt，不伪造字段。医学来源由编辑登记、审核人员核验，软件测试不能证明论文适用或内容临床正确。

## 发布前验收清单

- 执行文档检查、主题检查、单元测试、类型检查和生产构建。
- 三个本地服务运行后执行端到端测试，验证登录、角色权限、知识审核发布和下架。
- 验证 401、403、409、503、重试、草稿恢复和页面刷新。
- 验证深浅主题、窄屏、键盘导航和缺失静态资源 404。
- 部署后核对首页、健康接口及真实 API；前端健康检查不代替后端联调。

浏览器报告与截图为每次测试生成的本地文件，不随源码保留历史产物。
